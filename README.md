# מקום למחשבה — אפליקציית מוזיאון למובייל

גרסת PWA בעברית, עם גלריה לבנה, שש חידות חזותיות על ערים בישראל, מעבר בהחלקה, רמזים ואוסף אישי שנשמר במכשיר.

## הפעלה

מתוך תיקייה זו הפעילו `node server.cjs`, ואז פתחו http://localhost:4173.

## התקנה בטלפון

כדי להתקין בטלפון, יש להגיש את התיקייה מכתובת HTTPS שהטלפון יכול לגשת אליה. כתובת localhost במחשב אינה קישור לטלפון. ב־Safari בחרו שיתוף ← הוספה למסך הבית; בדפדפן התומך בהתקנה באנדרואיד השתמשו בכפתור ההתקנה או בתפריט הדפדפן.

האפליקציה נפתחת בחלון עצמאי. אחרי טעינה מוצלחת והשלמת שמירת הקבצים, המשחק יכול לפעול גם ללא אינטרנט. הגופן החיצוני מוחלף בגופן מערכת כשאינו זמין. התקדמות נשמרת מקומית לפי כתובת האתר; מחיקת נתוני האתר תמחק אותה.

## היקף

זו אפליקציית ווב הניתנת להתקנה, ולא חבילת App Store / Google Play. טרם פורסמה לכתובת ציבורית. פרויקט Flutter הקיים לא שונה. לשינוי חידות ואיורים ערכו את `levels` ו־`drawings` בקובץ `game.js`.
