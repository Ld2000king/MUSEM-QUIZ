# מקום למחשבה — 50 ערים בישראל

משחק מוזיאון למובייל עם 50 חידות, איורים מקוריים, רמזים ואוסף אישי. המפה מחולקת לחמישה אגפים של עשרה חדרים. ששת השלבים המקוריים נשארו באותו סדר, וההתקדמות הקודמת נשמרת.

[למשחק](https://ld2000king.github.io/MUSEM-QUIZ/)

## שתי גרסאות של המשחק

בתיקיית `app/` יש גרסת React Native של המשחק (Expo), שרצה גם כאפליקציית iOS/Android וגם כאתר דרך react-native-web. בשורש נשארת הגרסה הוותיקה בוונילה JS — היא זו שמוגשת כרגע ב־GitHub Pages, עד שהגרסה החדשה תחליף אותה.

### אפליקציית React Native (`app/`)

```
cd app
npm install
npm start          # Expo — סריקת QR באפליקציית Expo Go
npm run web        # הרצה בדפדפן
npm test           # בדיקות תוכן החידות והלוגיקה
npm run build:web  # ייצוא סטטי אל ../docs
```

הקוד בנוי מ־`View`/`Text`/`Pressable` ומ־`react-native-svg`: איורי החידות הם אותן מחרוזות SVG מהגרסה הוותיקה, ו־`SvgXml` מצייר אותן ישירות. `app/src/theme.js` מחזיק את פלטת המורשת שהייתה ב־`heritage.css`, ו־`app/src/data/` מחזיק את החידות. ההתקדמות נשמרת ב־AsyncStorage תחת אותם מפתחות (`cityMuseum.v2`), כך שמי שכבר שיחק באתר לא מאבד את האוסף.

#### אולם הכניסה

המסך הראשון הוא אולם השלדים: שלד לווייתן תלוי מהתקרה, שלד דינוזאור ארוך צוואר על אדן במרכז, ושלד ממותה בפינה — איורים מקוריים ב־`app/src/components/hallArt.js`, באותו סגנון שטוח של איורי החידות. מהאולם יוצאות שלוש דלתות: כניסה למוזיאון (בחירת תערוכה), המשך מהחידה שבה עצרתם, וחנות המזכרות. השיתוף וההתקנה עברו לכאן, כי בסרגל התחתון היה מקום לארבעה יעדים בלבד: הכניסה, התערוכות, האוסף שלי והחנות.

הסקלטונים מצוירים בגוון עצם בהיר על קיר האגוז ובגוון ספיה על קיר האלון, אחרת הם נבלעים בקיר הבהיר.

#### מטבעות

כל מוצג שמגלים שווה 5 מטבעות, אגף שלם של עשרה חדרים מוסיף 25, ותערוכה שהושלמה מוסיפה 100 — 1000 מטבעות בסך הכול בכל המוזיאון. המונה מופיע באולם הכניסה, בסרגל שמעל חדר התצוגה ובחנות.

הארנק **נגזר** מהאוסף (`app/src/coins.js`) ולא נשמר כמונה רץ, כך שהוא לא יכול לצאת מסנכרון עם ההתקדמות, והוא עובד גם על שמירה שנכתבה בגרסה הוותיקה — שאינה יודעת דבר על מטבעות. רק מה שהוצא נשמר, ובינתיים הוא תמיד אפס.

#### חנות המזכרות

החנות עדיין סגורה: המדפים ריקים, אין מה לקנות ואי אפשר להוציא מטבעות. היא מציגה את הארנק, את התקרה של 1000 המטבעות ואת טבלת הצבירה, כדי שיהיה ברור בשביל מה אוספים.

קישור ״התקנה במסך הבית״ באולם הכניסה מופיע רק בגרסת הווב, כי ההתקנה היא פעולה של הדפדפן.

### הגרסה הוותיקה (שורש הריפו)

הפעלה מקומית: `node server.cjs`, ואז http://localhost:4173.
בדיקות: `node test.cjs`.

אין צורך להתקין חבילות. ב־GitHub Pages מגישים את תיקיית השורש של `main`.

## תוכן

חידות חיבור תמונות, משחקי מילים ואותיות, וחידות זיהוי מקום המסומנות בנפרד. לכל חידה רמז והסבר אחרי פתרון. כתיבים קרית/קריית ותקוה/תקווה מתקבלים. `levels.js` מכיל את 44 השלבים הנוספים ואת איוריהם; `game.js` מכיל את ששת המקוריים ואת מנגנון המשחק. ב־`app/src/data/` יושב עותק של שני הקבצים האלה כמודולים, ובדיקה ב־`app/test.mjs` משווה אותם לשורש כדי שלא ייפרדו זה מזה כל עוד שתי הגרסאות חיות.

## התמונות בחידות

הקיר האחורי של החדר רחב דיו כדי ששני המוצגים יוצגו גדולים יותר, במסגרת דקה ועל פספרטו בהיר. לכל מוצג שלט קיר קריא, והקשה עליו פותחת אותו בתצוגה מוגדלת למלוא המסך — שימושי בחידות שבהן צריך לספור פרטים או לקרוא כתובת. במסכים נמוכים השלט והספסל נסתרים והשלט המרכזי יורד לרצפה, כדי שהתמונות לא יוסתרו. `artwork.css` מרכז את כל העיצוב הזה.

## מראה האגף: עץ, פליז וזכוכית

המוזיאון עוצב במראה "אגף מורשת" — קירות עץ אגוז, מסגרות פליז, רצפת פרקט ולוחיות פרשנות מפרגמנט. שני מתגי עיגול בכותרת (ליד כפתור העזרה) מאפשרים לבחור בין קיר כהה לקיר בהיר; הבחירה נשמרת בדפדפן ומשפיעה על כל התערוכות. `heritage.css` מגדיר את שני הפלטות דרך משתני CSS ומוחל אותם על ה־SVG של החדר וכל שאר הרכיבים.

הלוגו (`logo-mark.png`, מוצג בכותרת) ואייקוני ה-PWA (`icon-192.png`, `icon-512.png`) גזורים מאותה מסגרת זהב מאוירת, עם רפידה לבנה כדי לשרוד מיסוך עגול של אייקוני אנדרואיד.

## מובייל והתקנה

המשחק הוא PWA. אפשר להתקין ממסך השיתוף ב־Safari או מתפריט דפדפן תומך באנדרואיד. ההתקנה מחייבת כתובת HTTPS נגישה לטלפון. לאחר טעינה ושמירת הקבצים ניתן לשחק ללא חיבור. הגופן החיצוני מוחלף בגופן מערכת כשהוא אינו זמין.

התקדמות נשמרת בדפדפן לפי כתובת האתר; מחיקת נתוני האתר מוחקת אותה. זו אינה חבילת App Store או Google Play.

## תערוכות ושיתוף

כעת יש 80 מוצגים: 50 ערים בישראל, 10 ערים בארה״ב, 10 זמרים ישראלים ו־10 ספורטאים ישראלים. לכל תערוכה התקדמות נפרדת; שמירות ישנות של תערוכת ישראל עוברות אוטומטית למבנה החדש. `categories.js` מכיל את התוכן הנוסף.

כפתור ״שתף את המוזיאון עם חברים״ משתמש בחלונית השיתוף של המכשיר. כשאינה נתמכת מוצגות אפשרויות וואטסאפ, הודעה והעתקת קישור. הקישור מכיל רק מזהי תערוכות ומספרי החידות שנפתרו. הוא מציג צילום מצב לקריאה בלבד, אינו מעתיק התקדמות למכשיר המקבל ואינו כולל שם או פרטי חשבון. מי שמחזיק בקישור יכול לראות את האוסף המשותף.
